# Six record-keeping mistakes that distort a portfolio view

The most misleading portfolio result is often a precise-looking number built from incomplete records. These are six gaps worth checking.

## 1. Counting the same import twice

A repeated file or forwarded email should not create another copy of the same trade. Trackr+ uses import deduplication; verify the result when trying a new format.

## 2. Replacing a missing acquisition with zero cost

A sale without its purchase or evidenced allotment is incomplete history. A zero-cost guess can make the gain look larger while hiding the original problem.

## 3. Treating a rename as a new investment

A verified security-identity change should preserve the appropriate original acquisition history. It should not silently reset a holding period.

## 4. Counting an announced dividend as received

An announcement is not a payment record. Trackr+ keeps expected amounts separate from recorded income.

## 5. Ignoring investments already sold

A buy and sale can both be missing while today's holding quantity still matches. Historical transaction comparison checks more than an ending balance.

## 6. Comparing different scopes

A priced subset, all security holdings and a complete brokerage account including cash are different boundaries. Check exclusions, period and return units before comparing two totals.

These checks improve the quality of the records; they do not establish future returns. See [reproducible tracking](/blog/portfolio-tracker-vs-excel-google-sheets) and [benchmark comparisons](/blog/benchmark-portfolio-india).
