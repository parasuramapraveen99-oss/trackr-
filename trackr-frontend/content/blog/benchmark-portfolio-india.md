# How to compare your portfolio with an index fairly

“My portfolio is up” and “the index is up” are not enough to establish a fair comparison. Check what was measured and when the money was invested.

## Same money, same dates

A cash-flow-matched benchmark asks what the same invested amounts would have become if they had entered and left an index on the same dates. It is a comparison scenario, not a claim that you could buy an index level directly without costs.

Trackr+ can compare recorded security cash flows against stored Nifty total-return index levels. The selected index must be named consistently beside the result.

## Match the return basis

A total-return index includes its dividend treatment. Your personal return includes only income supported by recorded transactions. Missing dividend receipts can therefore limit the completeness of your comparison.

For a time-weighted chart, compare the portfolio's time-weighted series with the index series. Do not compare an annualised money-weighted rate with an unlabelled change in an index level.

## Read missing-data notices

If a holding has no reliable opening price or complete history, its cash flows must not remain in only one side of the comparison. The included scope and missing index dates should be visible.

## Difference versus contribution

Two returns can differ by percentage points. That difference is not the same as the rupee gap between terminal values, and individual stock XIRRs do not add up to portfolio XIRR.
